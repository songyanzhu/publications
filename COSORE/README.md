# Global soil respiration: UFLUX analysis

This repository contains a compact analysis script for the manuscript **“Global soil respiration and its share of ecosystem respiration: Spatial patterns and environmental controls”** (Songyan Zhu and co-authors).

The study uses the Unified FLUX (UFLUX) framework to examine global soil respiration ($R_s$) and its contribution to total ecosystem respiration ($R_s/R_{\mathrm{ECO}}$) during 2000–2024. It brings together eddy covariance estimates of gross primary productivity (GPP) and ecosystem respiration ($R_{\mathrm{ECO}}$), continuous soil chamber measurements from COSORE, and annual soil respiration records from SRDBv5. The analysis evaluates spatial patterns, environmental responses, annual carbon totals, and the combination of COSORE-based and SRDBv5-corrected estimates.

## What this script contains

[`COSORE_analysis.py`](COSORE_analysis.py) extracts the **data analysis** steps from the project notebooks into reusable functions:

| Analysis | Functions |
| --- | --- |
| Paired observation checks and validation | `validation_metrics`, `ratio_quality_control`, `ratio_validation` |
| SRDBv5 grid-year benchmarks and environmental response bins | `srdb_grid_year`, `binned_driver_response` |
| Area-weighted annual carbon totals and 2000–2024 trend | `grid_cell_area`, `annual_flux_pgC`, `corrected_annual_series` |
| Error-weighted combination of COSORE and SRDBv5 estimates | `map_fusion`, `bootstrap_mean_totals` |
| External comparison with the Huang soil respiration product | `huang_comparison` |
| Observation-site vegetation coverage and VPD sensitivity | `site_vegetation_shares`, `causal_vpd` |

The script does not download the source datasets, train the Stage 1–3 UFLUX prediction models, or generate the manuscript figures. The Stage 1 SmartForest4D implementation is in [GeoXAI](https://github.com/songyanzhu/geoxai/blob/main/geoxai/ai/models.py). The `causal_vpd` function fits the separate causal forest used for the VPD sensitivity analysis.

## Inputs and units

The command-line analysis expects the **processed** annual files from `3_output/UFLUXv1_corrected/`, named `2000-UFLUXv1-Rs.nc` through `2024-UFLUXv1-Rs.nc`. These files are inputs to the script, not generated by it.

For `corrected_annual_series`, the source notebook treats `Rs2` as an annual cumulative flux in g C m⁻² yr⁻¹, and `GPP` and `RECO` as mean daily rates in g C m⁻² d⁻¹. The function integrates them over the same valid land grid cells in every year. Other functions take explicitly supplied `pandas` tables or `xarray` arrays; their expected columns and units are documented in the Python docstrings. In particular, `map_fusion` needs the held-out SRDBv5 test indices from the residual-learning analysis; it does not generate or infer a new train/test split.

## Installation and use

Python 3.10 or later is required. Install the core analysis packages:

```bash
python -m pip install numpy pandas scipy xarray
```

Install `econml` and `lightgbm` only if running the causal forest analysis:

```bash
python -m pip install econml lightgbm
```

From the project directory, calculate the annual GPP, $R_{\mathrm{ECO}}$, and SRDBv5-corrected $R_s$ totals and the linear $R_s$ trend:

```bash
python COSORE_analysis.py --corrected-dir 3_output/UFLUXv1_corrected
```

For analyses requiring other inputs, import the functions into a Python session. For example:

```python
import pandas as pd
from COSORE_analysis import ratio_quality_control, ratio_validation

valid, qc_summary = ratio_quality_control(paired_daily_records)
metrics = ratio_validation(held_out_ratio_predictions)
print(qc_summary)
print(metrics)
```

Here, `paired_daily_records` must contain `Rs` and `RECO`, while `held_out_ratio_predictions` must contain `Chamber_Rs2RECO` and `UFLUX_Rs2RECO`. Supply actual processed tables rather than running this example with placeholder variables.

## Data and manuscript

The study data are deposited in [Zenodo record 23011179](https://zenodo.org/records/23011179). The independent Huang annual soil respiration product used for comparison is [available separately](https://doi.org/10.5281/zenodo.5909563). See the manuscript’s Materials and Methods and Supporting Information for the original observation sources, modelling stages, validation design, and interpretation of the results.
